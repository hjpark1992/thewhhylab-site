## 2. 벤치마킹에서 가져온 것

- **Section AI** (sectionai.com) — "You bought AI. That was the easy part." 문제 제기형 히어로, 전환 레이어 다이어그램, 서비스 5축, 고객 로고 → 사례 수치 → 후기 순서. 더와이랩의 "AI 도입은 했는데 일은 그대로" 메시지와 정확히 같은 결.
- **Elice** (elice.io) — 첫 화면에 도입 기관 수·이용자 수·정부 표창을 먼저 보여주는 **신뢰 선배치**, 성공사례 → 언론 → 인증 순.
- **Maven** — 학습 형식을 3종(코호트·워크숍·무료 레슨)으로 먼저 나눠 보여주는 카드 그리드.
- **Colorlib 기업교육 사이트 29선** — 로고 마퀴, 4단계 프로세스 시각화, ROI 수치, 듀얼 CTA, 상단 공지 바가 공통 패턴.
- **2026 트렌드** (line25, bubble, netguru 등) — 멀티 프로덕트에는 **벤토 그리드**, "크기보다 구조"의 볼드 타이포, 다크·그라데이션은 기본값, Core Web Vitals, 접근성(WCAG 2.1 AA). AI 생성 사이트가 다 비슷해지는 역트렌드 → 고유한 타이포·레이아웃이 차별점.

## 3. 디자인 원칙

1. **브랜드는 유지, 표현만 갱신** — 블루 `#2563ff`, Pretendard, 흰 바탕 + 딥네이비 다크 섹션. 로고 그대로.
2. **첫 화면 = 한 문장 + 증거** — 헤드라인 1개, 서브 1개, CTA 2개, 우측에 숫자·책·자격 배지 벤토.
3. **3단계 흐름을 사이트의 뼈대로** — Alignment(정렬) → Discovery(발굴) → 조직지능(축적). `ax-programs`가 이미 쓰는 구조를 홈에서 먼저 보여준다.
4. **섹션마다 다른 리듬** — 벤토 / 가로 스크롤 스냅 / 다크 피처 / 막대 차트 / 인용. 같은 "카드 3개"를 반복하지 않는다.
5. **모션은 절제** — 스크롤 리빌, 숫자 카운트업, 로고 마퀴, 헤더 축소. `prefers-reduced-motion`이면 전부 끔. JS 없이도 모든 콘텐츠가 보인다.
6. **접근성 기본** — 스킵 링크, 시맨틱 랜드마크, 키보드 메뉴(포커스 트랩·ESC), `aria-live` 상태, 포커스 링.

## 5. 파일

```
renewal/
├─ README.md              이 문서
├─ index.html             홈
├─ ai-hrd/index.html      서브페이지 템플릿(브레드크럼·페이지 내 네비·콘텐츠 리듬)
└─ assets/
   ├─ css/renewal.css     디자인 시스템 + 컴포넌트
   └─ js/renewal.js       헤더·메뉴·리빌·카운트업·마퀴
```

- 이미지·로고는 기존 `/shared/img/`를 **절대경로로 참조**(복사 없음). 실배포 시에도 그대로 동작.
- 폰트: Pretendard Variable(jsdelivr dynamic-subset) — `ax-programs`와 동일 방식.
- 줄바꿈 LF(AX_Discovery·ax-programs와 동일). BOM 없음. 기존 메인 페이지(CRLF)로 이식할 때는 치환 스크립트가 원본 줄바꿈을 따르므로 별도 변환 불필요.

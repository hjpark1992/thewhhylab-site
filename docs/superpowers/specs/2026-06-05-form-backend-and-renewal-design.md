## 2. Phase 1 — 폼 백엔드 아키텍처

### 2.1 전체 흐름
```
[전용 페이지]
  /contact/index.html   일반 교육 문의 (9필드 + 개인정보 동의)
  /apply/index.html     교육 멤버(강사) 모집 (15필드 + 파일 업로드)
        │ POST  (multipart/form-data, fetch)
        ▼
[서버] /api/submit.php          공통 진입점 (type 파라미터로 분기)
        ├─ 1. 스팸 차단: 허니팟 필드 + 최소 제출시간 검사
        ├─ 2. 검증: 필수값 / 이메일·연락처·출생년도 형식 / 파일 형식·용량
        ├─ 3. 저장: PDO prepared statement → MySQL
        ├─ 4. 파일: 보호 폴더에 랜덤 파일명으로 저장 (멤버 폼만)
        ├─ 5. 메일: thewhhylab@naver.com 으로 알림 (멤버 폼은 프로필 첨부)
        └─ 6. 응답: JSON { ok, message } → 페이지에서 aria-live로 표시
[설정] /api/config.php          DB 접속·수신메일 등 실제 값 (git 비추적)
       /api/config.sample.php   채워넣기용 템플릿
[보호] /api/uploads/.htaccess   업로드 폴더 직접 접근 차단
```

### 2.2 디렉터리 / 파일 구성 (신규)
```
/contact/index.html         일반 문의 폼 페이지
/apply/index.html           멤버 모집 폼 페이지
/shared/js/forms.js         폼 공통 JS (검증·제출·상태표시) — 신규
/shared/css/site.css        기존 파일에 폼 스타일 토큰 추가(외형 일관)
/api/submit.php             제출 처리 엔드포인트
/api/config.sample.php      설정 템플릿 (실제 config.php는 서버에서 작성)
/api/lib/db.php             PDO 연결 헬퍼
/api/lib/mailer.php         메일 발송 헬퍼 (mail() 기반, SMTP 교체 지점 분리)
/api/lib/validate.php       검증 헬퍼
/api/uploads/.htaccess      "Deny from all"
/db/schema.sql              테이블 생성 스크립트
```
- 폼 페이지는 기존 nav/menu/footer 마크업과 `site.css` 디자인 토큰을 그대로 재사용 →
  외형 일관성 유지(별도 디자인 변경 아님).
- 메일 발송은 `mailer.php` 한 곳으로 격리. 국내 호스팅 `mail()` 도달률 문제 시
  PHPMailer(SMTP)로 이 파일만 교체하면 됨. **DB 저장은 항상 수행**되므로 메일 누락 시에도 데이터는 안전.

### 2.3 보안 / 운영 판단 (자체 결정 사항)
- **스팸 차단**: 화면에 보이지 않는 허니팟 필드 + "폼 로드 후 3초 이내 제출 차단".
  CAPTCHA는 도입하지 않음(사용자 마찰 ↑, 현 트래픽 규모에 과함 — YAGNI).
- **입력 escape**: 저장은 PDO prepared statement, 메일 본문은 `htmlspecialchars`.
- **CSRF**: 공개 문의 폼 특성상 토큰 미도입(상태 변경이 아닌 단방향 접수). 허니팟으로 봇만 차단.
- **파일 업로드**: 허용 확장자 화이트리스트(pdf, ppt, pptx, doc, docx, jpg, jpeg, png),
  MIME 재검증, 최대 10MB, 저장 파일명은 랜덤(원본명은 DB에 별도 보관),
  `/api/uploads/`는 `.htaccess`로 외부 직접 접근 차단.
- **설정 분리**: DB 비밀번호 등은 `config.php`(서버에만 존재). 저장소엔 `config.sample.php`만.
- **자동 회신 메일**: v1 미포함(YAGNI). 필요 시 `mailer.php`에 신청자 회신 1줄 추가 가능.

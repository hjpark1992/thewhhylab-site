# AX DISCOVERY 원본 이미지 보관 폴더

최종 웹·PDF 제작에 사용할 고해상도 원본을 아래 폴더에 넣어 주세요.

- `logo/`: 더와이랩 로고 SVG 또는 투명 PNG
- `book/`: 교재 표지, 책 목업, 교재 내부 캔버스
- `worksheets/`: 웹 워크시트 원본 화면
- `badges/`: 자격 배지 1급·2급 SVG 또는 투명 PNG
- `photos/`: 교육 현장 및 강사 사진
- `proof/`: 공개 가능한 사례·후기·성과 이미지

## 권장 규격

- 로고·배지: SVG 우선, 또는 긴 변 1600px 이상의 투명 PNG
- 화면 캡처: 원본 해상도 PNG, 가능하면 1920px 이상
- 사진: 긴 변 2400px 이상의 JPG 또는 PNG
- 교재 목업: 투명 배경 PNG 권장

고객명, 이메일, 프로젝트 정보 등 공개하면 안 되는 정보는 제거한 파일을 넣어 주세요.
파일명은 가능하면 영문 소문자와 하이픈을 사용해 주세요.

예: `book-cover.png`, `worksheet-hta.png`, `badge-level-2.svg`

# AX DISCOVERY HTML 상세페이지 제작 지침

이 문서는 1~3페이지를 HITL 방식으로 반복 수정하면서 확인된 사용자의 의도와 디자인 판단 기준을 바탕으로, 4~11페이지까지 확장한 작업 기준서다. 이후 모든 페이지는 이 문서를 먼저 확인하고 동일한 원칙으로 제작한다.

HITL로 세부 배치까지 확정된 페이지는 다음과 같다.

1. 관심/첫 화면
2. 차별성
3. 산출물

4~11페이지는 원본 제안서의 흐름과 이 문서의 공통 원칙으로 제작한 전체 시안이며, 이후 사용자 검토 결과를 페이지별 기준에 추가한다. 확정된 페이지를 수정할 때는 해당 페이지의 고유 기준과 이 문서의 공통 원칙을 함께 적용한다.

## 1. 프로젝트의 목적

하나의 HTML 콘텐츠로 다음 두 결과물을 만든다.

1. 온라인에서 보는 일반적인 제품·서비스 홍보용 상세페이지
2. 고객에게 전달하는 A4 가로형 PDF 홍보자료

웹을 인쇄물처럼 보이게 만들면 안 된다. 웹에서는 풀폭 랜딩페이지로 자연스럽게 이어지고, 인쇄할 때만 각 `.pdf-page` 섹션이 A4 가로 한 장으로 변환되어야 한다.

## 2. 핵심 대상과 의사결정 맥락

이 페이지의 주 대상은 프로그램 도입을 검토하거나 의사결정하는 다음 사람들이다.

- HR·교육 담당자
- AX·DX 추진팀
- 현업 팀장·실무자
- 경영진·사업 리더

모든 페이지는 이들이 짧은 시간 안에 다음 질문에 답할 수 있게 구성한다.

- 왜 이 프로그램이 필요한가?
- 다른 프로그램과 무엇이 다른가?
- 교육 후 조직에 무엇이 남는가?
- 실제 도입은 어떻게 진행되는가?

## 3. 콘텐츠 표현 원칙

### 3.1 한국어를 우선한다

- 장식적인 영어 소제목보다 직관적인 한국어를 우선한다.
- `AX DISCOVERY`, `AX`, `DX`, `3R`처럼 고유명사나 통용 약어만 유지한다.
- 영어가 정보 전달에 필요하지 않으면 한국어로 바꾼다.
- 작은 영문 라벨이 중요한 한국어 메시지보다 먼저 읽히지 않게 한다.

### 3.2 숫자보다 숫자가 의미하는 가치를 먼저 보여준다

숫자만 크게 보여주지 말고 무엇을 의미하는지 하나의 문장처럼 읽히게 한다.

- `10` → `10개의 구조화된 캔버스`
- `6` → `6개의 산출물`
- `3R` → `3R 전략`

설명은 명사 나열이 아니라 조직이 얻게 되는 가치 또는 활용 방식을 말한다.

### 3.3 검증되지 않은 내용은 만들지 않는다

- 고객사, 성과 수치, 후기, 실적, 가격, 연락처를 임의로 만들지 않는다.
- 확정되지 않은 내용은 `[내용 입력 필요]` 또는 명확한 확인 문구로 남긴다.
- 자격 관련 표현은 현재 승인된 문구인 `자격 취득 가능`을 사용한다.

### 3.4 줄바꿈은 의미 단위로 통제한다

- 제목과 핵심 문장은 조사나 단어 중간에서 어색하게 줄이 바뀌지 않게 한다.
- 한 줄로 보여야 하는 문구는 충분한 너비를 먼저 확보한 뒤 `white-space`를 사용한다.
- 글자를 과도하게 줄여 한 줄을 맞추지 않는다.
- 모바일에서는 필요하면 카드나 항목을 세로로 재배치해 가독성을 지킨다.

### 3.5 표나 선 안의 내용이 한쪽에 치우치지 않도록 조정한다.

- 줄바꿈됨 문구를 한줄로 끌어올려 선이나 표가 길어지는 경우 포함된 모든 내용이 동일하게 분배 되도록 조정 한다.

### 3.6 특별히 강조를 언급하지 않는 경우 내용들이 동일한 비율로 자리 차지 하도록 한다.

- 도형 안에 내용을 넣는 경우 동일 비율의 박스 크기로 구성 한다.

## 4. 웹과 PDF의 역할 분리

### 4.1 웹 화면

- 일반적인 B2B 제품·서비스 랜딩페이지처럼 보여야 한다.
- 섹션은 전체 화면 너비를 사용하고 콘텐츠는 약 1200px 안에서 정렬한다.
- 웹에서 A4 용지 카드, 페이지 그림자, 회색 페이지 간 배경을 사용하지 않는다.
- 모바일에서는 페이지 전체를 축소하지 않고 콘텐츠를 실제로 재배치한다.
- 카드와 이미지가 한 열로 내려가더라도 본문 크기와 터치 영역을 유지한다.

### 4.2 PDF 출력

- `@page { size: A4 landscape; margin: 0; }`을 사용한다.
- 각 `.pdf-page`는 297mm × 210mm 한 장이다.
- 웹 전용 메뉴와 CTA는 숨기고, PDF 전용 로고·페이지 번호는 표시한다.
- 각 페이지의 실제 콘텐츠가 안전 영역 안에 들어가야 한다.
- `overflow: hidden`으로 잘못된 배치를 감추지 않는다.

### 4.3 로고 사용

- 웹에서는 상단 고정 메뉴의 로고만 표시한다.
- 같은 화면 본문에 로고를 반복하지 않는다.
- PDF에서는 웹 메뉴가 출력되지 않으므로 각 인쇄 페이지에 로고를 한 번만 표시할 수 있다.

## 5. 비주얼과 이미지 배치 원칙

### 5.1 사용자 참고 이미지 해석 규칙

사용자가 캡처와 함께 지시한 내용이 최우선이다.

- `배치만 참조`라고 하면 상대적 위치, 크기, 앞뒤 순서만 참고한다.
- 참고 이미지의 문구, 색상, 디자인까지 복사하지 않는다.
- `동일하게 배치`라고 하면 창의적으로 재해석하지 말고 위치 관계를 그대로 구현한다.
- 배경 요소와 핵심 이미지의 우선순위를 구분한다. 배경 도형은 핵심 이미지를 위해 가려질 수 있다.
- 구현 전 `좌측/우측`, `상단/하단`, `전면/후면`, `겹쳐도 되는 영역`을 문장으로 먼저 정리한다.

### 5.2 이미지 품질

- 제공된 원본 이미지를 우선 사용한다.
- 이미지의 가로세로 비율을 강제로 바꾸지 않는다.
- `height: auto`, `object-fit: contain`, 명시적 `aspect-ratio`로 찌그러짐을 방지한다.
- 실제 화면이나 교재 내용을 읽어야 하는 이미지는 장식 요소보다 크게 보여준다.
- 제목, 주요 UI, 표, 워크시트를 다른 이미지나 배지가 가리지 않게 한다.

### 5.3 중첩 배치

- 중첩은 제품 묶음을 보여주기 위한 경우에만 사용한다.
- 겹치는 순서가 사용자의 참고 이미지와 일치해야 한다.
- 핵심 정보 영역은 가리지 않고, 모서리나 여백 부분만 겹친다.
- 배경 원, 그라데이션, 격자는 실제 제품 이미지보다 항상 뒤에 둔다.

## 6. 1페이지 확정 기준

1페이지는 이후 페이지의 타이포그래피, 여백, 이미지 처리 기준이 된다.

### 6.1 문구

- 상단 라벨: `AX 업무 혁신 프로그램`
- 제목:
  - 강조색: `AI로 일하는 방식`
  - 검은색: `을 다시 설계하는 전략적 전환`
- 추천 대상:
  - HR·교육 담당자
  - AX·DX 추진팀
  - 현업 팀장·실무자
  - 경영진·사업 리더
- CTA 화살표: 수평 방향 `→`

### 6.2 제품 비주얼 배치

사용자가 제공한 레퍼런스의 상대적 배치를 그대로 유지한다.

1. 교재는 좌측 상단의 전면에 둔다.
2. 워크시트는 교재 뒤쪽의 우측 하단에 둔다.
3. 교재 하단과 워크시트 좌측 상단이 일부 겹친다.
4. 교재를 우측 상단으로 이동하지 않는다.
5. 워크시트는 파란 원형 배경을 가려도 된다.
6. 워크시트 화면은 원본 비율로 선명하게 보여야 한다.
7. 자격 배지는 우측 상단에 둔다.
8. 문구는 `자격 취득 가능`으로 표시한다.
9. 자격 문구 박스는 흰색 라운드 형태이며 약 20% 투명도를 적용한다.
10. 배지는 문구 박스 높이보다 크게 보이게 한다.

### 6.3 핵심 구성 문구

- `10개의 구조화된 캔버스`
  - `업무를 단계적으로 해체하고 재설계`
- `6개의 산출물`
  - `교육 후 현장에서 활용하는 실행 결과물`
- `3R 전략`
  - `줄이기·재배치·가치창출로 이어지는 전환 구조`

세 항목은 특정 항목만 커 보이지 않도록 동일한 너비로 배치한다. 각 설명은 데스크톱과 PDF에서 한 줄로 보여야 하며, 모바일에서는 항목 전체 너비를 확보해 한 줄을 유지한다.

## 7. 2페이지 현행 기준

2페이지는 차별점을 나열하는 페이지가 아니라, 교재에서 실습과 자격으로 이어지는 하나의 학습 경험을 보여준다.

### 7.1 문구

- 상단 라벨: `— 차별성` (번호 없이 앞쪽 대시는 유지하고, 기본 섹션 라벨의 두 배 크기로 표시)
- 제목 1행: `교재·웹 실습툴·자격증 연계까지,`
- 제목 2행: `더와이랩만 갖춘 세 가지`
- `교재·웹 실습툴·자격증 연계`에는 블루-시안 강조색을 적용하고, `까지,`와 둘째 줄은 검은색으로 유지한다.
- 별도의 설명문을 두지 않고 제목에서 세 가지 차별성과 연결 구조를 직접 전달한다.
- 카드 라벨:
  - `자체 출간 교재`
  - `교재 연동 실습`
  - `전문 자격 연계`

### 7.2 카드 구성

1. 자체 출간한 `AX DISCOVERY` 교재와 10개의 구조화된 캔버스를 보여준다.
2. 교재와 연결된 웹 워크시트에서 실습 과정이 기록된다는 점을 보여준다.
3. 과정 이수 후 별도 자격 검정 시험을 통해 자격 취득이 가능하다는 점을 보여준다.
4. 영문 장식 라벨을 쓰지 않고 한국어만으로 각 차별점을 이해할 수 있게 한다.
5. 세 카드 중 특정 항목을 별도로 강조하라는 지시가 없으므로 동일한 너비와 높이로 배치한다.
6. 웹 데스크톱과 PDF는 3열, 모바일은 1열로 재배치하되 각 카드의 비율과 정보 위계는 동일하게 유지한다.
7. 교재·워크시트·배지는 원본 비율을 유지하며, 제목과 설명을 가리지 않는다.
8. 세 카드 모두 흰색 바탕과 짙은 본문색을 사용하며, 자격 카드만 어두운 배경으로 강조하지 않는다.
9. 카드의 텍스트 영역과 하단 시각자료 영역을 분리한다. 이미지끼리는 일부 겹칠 수 있지만 라벨·제목·본문·주석을 가리면 안 된다.
10. 교재 카드는 교재 표지를 위쪽에 크게 놓고 HTA 캔버스 한 장을 그 아래 중앙에 정렬한다.
11. 웹 실습툴 카드는 두 화면을 기울이지 않고 같은 너비로 위아래에 정렬한다.
12. 자격 카드는 과정 수료 배지를 왼쪽 위, AX 전략기획전문가 2급 배지를 오른쪽 아래에 크게 배치한다.
13. 교재 이미지는 카드 폭의 약 64%, 캔버스는 약 56%를 차지하도록 조정하여 기준 이미지의 시각적 무게를 따른다.
14. 교재와 웹 실습툴 이미지는 절대 위치를 사용하지 않고 본문 다음의 세로 흐름에 배치하여, 화면 크기와 관계없이 본문과 절대 겹치지 않게 한다.
15. 자격 카드 하단의 자격 검정 운영 조건 주석은 표시하지 않는다.
16. 교재와 캔버스 사이, 두 워크시트 사이에는 명확한 간격을 둔다. 두 배지는 이전 시안처럼 크고 가깝게 겹쳐 배치한다.
17. 이미지 크기는 카드의 안쪽 콘텐츠 폭이 아니라 카드 전체 폭을 기준으로 환산하여 기준 이미지와 같은 점유율을 유지한다.

## 8. 3페이지 현행 기준

3페이지는 교육 항목을 설명하는 페이지가 아니라, 교육 후 조직과 참여자에게 남는 실행 자산을 보여준다.

### 8.1 문구

- 상단 라벨: `— 산출물` (2페이지의 `— 차별성`과 동일한 크기와 형식)
- 제목 1행: `교육으로 끝나지 않습니다.`
- 제목 2행: `결과물이 현업에서 다시 쓰이는 실행 자산`
- 제목 2행에는 블루-시안 강조색을 적용한다.
- 설명: `교육이 끝나는 순간, 참여자의 손에는 현업에서 바로 검토하고 실행할 AX 과제와 설계 문서가 남습니다.`
- 하단 왼쪽 라벨은 표시하지 않는다.
- 산출물의 세부 명칭과 범위는 확정 커리큘럼에 맞춰 조정된다는 안내를 유지한다.

### 8.2 산출물 카드

카드 안의 `과제`, `진단`, `설계`, `구현`, `명세`, `확산` 역할 박스는 표시하지 않는다. 번호, 산출물명, 현업 활용 설명만으로 정보 위계를 단순화한다.

1. `01` — AX 퀵윈 문제정의서
2. `02` — 데이터 준비도 진단서
3. `03` — AI 협업 워크플로우
4. `04` — AI 에이전트 프로토타입
5. `05` — 에이전트 명세서
6. `06` — 현장 확산 전략서

모든 카드는 동일한 너비, 높이, 내부 여백을 사용한다. 번호는 위, 산출물명은 중앙, 현업 활용 설명은 아래에 정렬한다. 설명은 산출물의 이름을 반복하지 않고 현장에서 무엇에 쓰이는지를 한 문장으로 설명한다.

### 8.3 로고와 출력

- 웹에서는 고정 메뉴에 로고가 있으므로 3페이지 본문 로고를 숨긴다.
- PDF에서는 웹 메뉴가 숨겨지므로 인쇄 전용 로고를 페이지 상단에 표시한다.
- 데스크톱과 PDF는 3열 2행, 모바일은 1열로 재배치한다.
- 하단 안내 문구는 우측에만 배치하며, 왼쪽에 별도의 라벨이나 문구를 추가하지 않는다.

## 9. 남은 페이지의 흐름

사용자가 확정한 순서를 유지한다.

1. 관심/첫 화면
2. 차별성
3. 산출물
4. 문제 공감
5. 관점 전환
6. 3R 해결 원리
7. 1단계 REDUCE 줄이기
8. 2단계 REALLOCATE 재배치
9. 3단계 REINVENT 재창출
10. 결과·근거
11. 도입·문의

각 페이지는 하나의 핵심 의사결정 질문만 다룬다. 슬라이드처럼 항목을 나열하기보다 상세페이지의 이야기 흐름으로 다음 섹션을 읽게 만든다.

### 9.1 10페이지 결과·근거 자료

10페이지의 사례·후기·성과는 사용자가 제공한 `주요 대기업 그룹사 및 공공기관 현업 구성원이 검증한 AX Discovery 교육효과` 자료를 근거로 제작한다. 이 자료에 포함된 수치와 후기 문구는 사용할 수 있으며 `[내용 입력 필요]`로 대체하지 않는다.

#### 교육효과 수치

- `4.9 / 5.0` — 교육 전반 만족도
- `100%` — 동료·지인 추천 의향
- `5.0 / 5.0` — 강사 강의 만족도
- `98%` — 현업 적용 자신감

#### 후기의 핵심 메시지

1. 워킹 플로우와 일하는 방식 자체를 다시 정의했다.
2. 막연했던 AI 활용을 실행 가능한 AX로 구체화했다.
3. 생산성을 높이고 원가를 절감할 가능성을 확인했다.
4. AI 에이전트 프로토타입을 직접 만들어본 점이 유익했다.

#### 사용 조건

- 참여 기업은 제공 자료와 같이 `S그룹`, `H그룹`, `C그룹` 등 익명 표기를 유지한다.
- 수치와 후기의 의미를 과장하거나 자료에 없는 인과관계·성과를 추가하지 않는다.
- 표본 수, 조사 시점, 조사 방식 등 제공 자료에서 확인되지 않는 정보는 임의로 작성하지 않는다.
- 10페이지 제작 시 제공 자료의 문장을 웹 가독성에 맞게 줄일 수 있지만, 원래 의미가 달라지지 않게 한다.
- 4개의 수치와 4개의 후기를 모두 동일한 비중으로 나열하기보다, 핵심 수치가 먼저 읽히고 후기가 이를 뒷받침하도록 정보 위계를 설계한다.

### 9.2 4페이지 문제 공감

- 핵심 질문은 `AI 툴을 도입했는데, 왜 성과는 확산되지 않을까요?`로 제시한다.
- 원본 제안서의 문제를 `특정 부서에서만 쓰임`, `비용이 함께 늘어남`, `도구의 빠른 범용화` 세 가지로 구조화한다.
- 세 문제는 동일한 크기의 카드로 보여주고, 어느 한 항목만 더 중요한 것처럼 강조하지 않는다.
- 마지막에는 `도구의 문제가 아닙니다. 일하는 방식을 다시 설계해야 합니다.`라는 한 문장으로 다음 페이지의 관점 전환에 연결한다.

### 9.3 5페이지 관점 전환

- `기존 접근`과 `성과를 만드는 순서`를 좌우 대비로 보여준다.
- 기존 접근은 솔루션 도입·컨설팅 진단·AI 활용 교육·1회성 해커톤의 한계를 설명한다.
- 대안은 `도구보다 에이전트로 시작 → 현업에서 반복 수정 → 실효성 검증 후 개발` 순서다.
- 하단 참고 문구와 외부 연구 링크는 표시하지 않는다.
- 화이트톤 배경 안에서 기존 접근은 흰색 카드, 성과를 만드는 순서는 옅은 블루 카드로 구분한다.

### 9.4 6페이지 3R 해결 원리

- 핵심 구조는 `100 → 10 + 90 → 10×`로 시각화한다.
- 100은 기존 투입, 10은 AX로 줄인 투입, 90은 재배치 자원, 10×는 새로운 가치를 뜻한다.
- REDUCE·REALLOCATE·REINVENT 세 단계는 동일한 크기의 카드로 배치한다.
- 각 카드는 `핵심 질문 → 대상 업무/기회 예시` 순서로 읽히게 한다.
- 기본 과정은 1단계 카드 폭에, 심화 과정은 2·3단계 카드의 합친 폭에 맞춘 두 개의 긴 박스로 안내한다.

### 9.5 7페이지 1단계 REDUCE 줄이기

- `기반 정렬 → 문제 발견 → 진단·설계 → 정량화·구현 → 검증·확산`의 5단계 흐름을 사용한다.
- 데스크톱과 PDF에서는 한 줄의 연결 흐름, 모바일에서는 한 단계씩 세로로 재배치한다.
- 각 단계는 활동 설명과 남는 결과물을 함께 보여준다.
- 결과물 이름은 3페이지의 산출물과 충돌하지 않도록 같은 용어를 사용한다.
- 상단 섹션 타이틀은 `1단계 REDUCE 줄이기`로 표시한다.

### 9.6 8페이지 2단계 REALLOCATE 재배치

- 7페이지와 같은 연결 카드 양식을 사용하며 `재투입 과제 발굴 → 프로세스 설계 → 검증과 확산`의 3개 모듈로 구성한다.
- 1단계에서 확보한 자원을 고부가가치 업무에 재배치하고 인간-AI 협업 구조와 성과향상 에이전트를 설계하는 흐름을 보여준다.
- 산출물은 `핵심역량 전환·성과향상 과제`, `성과향상 AI 에이전트`, `에이전트 명세서·성과향상 AX 확산전략 보고서`를 사용한다.
- 상단 섹션 타이틀은 `2단계 REALLOCATE 재배치`로 표시한다.

### 9.7 9페이지 3단계 REINVENT 재창출

- 7페이지와 같은 연결 카드 양식을 사용하며 `기회 발굴 → 가설 수립 → 검증과 보완 → 고도화와 발표`의 4개 모듈로 구성한다.
- 신규시장·목표고객·10배 가치가설을 검증하고 AI 에이전트와 실제 개발 요구사항을 고도화하는 흐름을 보여준다.
- 산출물은 `신규 가치 창출 과제`, `고객·시장 검증계획서·사업화 체크리스트`, `고객·시장 검증 결과표·신규가치 창출 중간보고서`, `실제 개발을 위한 PRD·최종 발표자료`를 사용한다.
- 상단 섹션 타이틀은 `3단계 REINVENT 재창출`로 표시한다.

### 9.8 10페이지 교육효과

- 4개의 수치를 상단에 먼저 보여주고, 4개의 후기가 그 수치를 뒷받침하는 구조로 배치한다.
- 후기 카드의 높이와 비중은 동일하게 유지한다.
- 원본 자료의 익명 기업 표기와 의미를 유지하며, 표본 수나 조사 방식을 추가하지 않는다.

### 9.9 11페이지 도입·문의

- 핵심 문구는 `AX는 조직의 전략이자, 개인의 실행 역량입니다.`다.
- 조직이 얻는 가치와 참여자가 얻는 가치를 동일한 두 카드로 비교한다.
- 문의 정보는 흰색 패널로 분리해 PDF에서도 링크와 연락처가 즉시 보이게 한다.

## 10. 페이지 디자인 규칙

- 장식보다 메시지와 정보 위계를 우선한다.
- 제목, 한 문장 설명, 핵심 시각화 순서로 읽히게 한다.
- 중요한 문구만 블루-시안 그라데이션으로 강조한다.
- 모든 문구를 강조색으로 만들지 않는다.
- 1~10페이지는 흰색·아주 옅은 블루·쿨그레이 범위의 화이트톤 배경만 사용한다.
- 마지막 11페이지 `도입·문의`만 짙은 네이비 배경을 사용한다.
- 섹션 라벨은 필요한 페이지에만 사용하며, 7~9페이지에는 각 장표의 단계명인 `1단계 REDUCE 줄이기`, `2단계 REALLOCATE 재배치`, `3단계 REINVENT 재창출`을 표시한다.
- 표시하는 섹션 라벨은 웹 32px, PDF 20pt를 기준으로 하며 페이지별로 임의 축소하지 않는다.
- 카드가 필요할 때만 라운드와 그림자를 사용한다.
- 같은 형태의 카드만 반복해 페이지 전체가 템플릿처럼 보이지 않게 한다.
- CTA 아이콘과 화살표는 방향과 정렬이 명확해야 한다.
- 배경 도형은 핵심 콘텐츠를 밀어내거나 가독성을 해치지 않아야 한다.
- 의미 없는 영문 약어를 아이콘처럼 사용하지 않는다. 한국어 역할어가 더 빠르게 이해되면 한국어를 사용한다.
- 추상적인 홍보 문구보다 해당 페이지에서 제공하는 가치와 연결 구조를 제목에서 바로 말한다.

### 10.1 가독성 기준

- 웹의 주요 본문과 카드 설명은 16px 미만으로 줄이지 않는다.
- PDF의 핵심 본문은 14pt 이상으로 구성한다.
- PDF의 보조 설명은 12pt 이상으로 구성한다.
- PDF의 라벨과 정보 문구는 10pt 이상으로 구성한다.
- 페이지 번호, 푸터, 법적·운영 조건 주석만 10pt 미만을 허용한다.
- 어두운 배경의 설명문은 흰색 기준 70% 이상의 대비를 확보한다.
- 글자 크기를 맞추기 위해 문장을 임의로 축소하지 않고, 카드 높이·여백·문장 길이를 함께 조정한다.
